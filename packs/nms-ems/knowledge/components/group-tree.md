# Group Tree Component

## 역할
site/group/NE를 선택하는 tree UI다.

## 관찰된 화면
- `Dashboard > Topology`
- `Equipment > ShelfView`
- `NE Configuration > MEF Service Management`

## 관찰된 구조
- `wc-treeview`
- `wc-treenode-item`
- `wc-treenode-content`
- site icon 예: `icon-uems-site`

## 작업 기준
- tree 선택은 조회 대상과 Detail panel 내용을 바꿀 수 있다.
- tree node expand/collapse는 조회 작업으로 볼 수 있지만, node 생성/삭제/이름 변경은 금지한다.
- 매뉴얼 캡처에서는 tree 선택 상태가 어떤 화면 정보를 결정하는지 설명한다.
