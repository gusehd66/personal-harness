# Detail Panel UI

## 사용 시점
우측 Detail panel, 선택 객체 속성, 읽기/편집 가능한 form 영역을 설명하거나 수정할 때 사용한다.

## 관찰된 위치
- `Dashboard > Topology`: 우측 `Detail` card
- `Equipment > ShelfView`: 우측 `Detail` card

## Dashboard > Topology
Topology object를 선택하면 우측 Detail panel에 다음 필드가 표시된다.

- `Parent Group`
- `Name`
- `Description`

## Equipment > ShelfView
unit을 선택하면 우측 Detail panel에 다음 영역이 표시된다.

- `Selected Unit`
- `Unit Info`
- `Slot Number`
- `Unit Type`
- `Equip Status`
- `Unit Command`
- `Admin Status`
- `PM Initialize`
- `LED Test`
- `Information`

## 작업 기준
- Detail panel은 단순 부가 영역이 아니라 선택 상태와 연결된 주요 정보 영역이다.
- 매뉴얼 캡처에서 Detail panel이 비어 있으면 어떤 객체를 선택해야 정보가 표시되는지 설명한다.
- 입력 필드가 보여도 조회 작업에서는 값을 변경하지 않는다.
- disabled/read-only로 보이는 필드와 실제 수정 가능한 필드를 구분해서 설명한다.
