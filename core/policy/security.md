# 범용 보안 정책

## 기록·출력·커밋 금지 정보

다음 정보는 채팅, 실행 기록, 문서, commit 메시지에 그대로 남기지 않는다.

- password, secret, API key, private certificate
- access token, cookie, 전체 authorization header
- 개인정보 또는 고객 식별 가능 데이터
- 운영 환경의 실제 데이터와 연결 정보

근거가 필요하면 민감값을 마스킹하고, 문제를 설명하는 데 필요한 최소 필드와 파일·행만 남긴다.

## 안전한 작업 방식

- local debugging에 운영 credential을 사용하지 않는다.
- 인증·권한 검사를 우회하는 방법을 일반적인 해결책으로 제안하지 않는다.
- 사용자가 임시 진단 우회를 명시적으로 요청한 경우에도 임시 목적, 활성 기간, 제거 기준을 함께 기록한다.
- 민감정보 후보를 발견하면 값은 복사하지 말고 경로·행·판정만 기록한다.
