# 범용 지식 승격 플레이북

## 목적

대화에서 얻은 사실을 다음 작업에서도 재사용할 수 있도록 적절한 저장 계층에 남긴다. Codex memory는 recall layer이며 필수 규칙의 유일한 저장소가 아니다.

## 저장 위치

| 종류 | 저장 위치 |
| --- | --- |
| 작업 한 번의 증거와 실패 | 프로젝트 `.harness/runs/` |
| 프로젝트 필수 규칙과 실제 구조 | 프로젝트 `AGENTS.md` 또는 `docs/` |
| 여러 프로젝트의 일반 원칙 | `core/` |
| 특정 업무·제품군에만 적용되는 지식 | 해당 `packs/` |
| 반복 가능한 독립 절차 | `skills/` |
| 안정적인 사용자 선호 | Codex memory 규칙이 허용하는 저장소 |
| 최신성이 중요한 사실 | source, 로그, 공식 문서, 런타임 조회 |

## 판단 규칙

- 검증되지 않은 추측과 프로젝트별 예외를 범용 규칙으로 올리지 않는다.
- 비밀번호, 토큰, 개인정보, 고객 데이터는 어느 계층에도 저장하지 않는다.
- 같은 사실을 여러 계층에 복제하지 않는다.
- 업데이트하지 않으면 결과 보고에 `지식/문서 업데이트 없음`과 이유를 남긴다.
