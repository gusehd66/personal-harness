# 범용 코드 리뷰 플레이북

## 리뷰 우선순위

심각도 순서로 실행 가능한 지적 사항을 제시한다.

1. 버그 또는 동작 회귀
2. 보안 또는 데이터 노출 위험
3. null, empty, timeout, retry, permission 처리 누락
4. 테스트 또는 실제 검증 공백
5. 유지보수 위험

## 근거

각 지적에는 가능한 경우 다음을 포함한다.

- 파일과 좁은 line reference
- 현재 동작과 기대 동작
- 재현 조건 또는 영향받는 호출자
- 검증 상태와 남은 공백

실행 가능한 지적 사항이 없으면 그 사실과 남은 검증 공백을 함께 적는다.
