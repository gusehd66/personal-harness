# 목적

변경 이력, 중복 규칙, 오래된 경로를 덧붙이는 대신 대상 문서를 현재의 단일 기준본으로 정리한다.

# 절차

1. 사용자 요청에서 정리 대상과 허용 범위를 확정한다.
2. 대상 문서 전체와 연결된 canonical 문서를 먼저 읽는다.
3. 현재 source, 설정, 소비자와 맞지 않는 설명·경로·중복을 식별한다.
4. 미래 실행에 필요한 현재 규칙만 남기고 대상 문서를 최소 구조로 다시 쓴다.
5. 관련 문서의 링크와 실제 소비자 참조를 확인한다.
6. `harness-verify`로 정리 결과와 남은 미검증을 구분한다.

# 규칙

- 사용자가 요청하지 않은 파일을 새로 만들거나 구조를 넓히지 않는다.
- changelog가 아닌 문서에는 이전/이후 패치 흔적을 남기지 않는다.
- 판단이 필요한 충돌은 임의로 해결하지 않고 근거와 선택지를 보고한다.
- NMS/EMS 사실이 포함되면 Pack과 현재 근거를 확인한다.
